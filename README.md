# Cage Kings: Street Football

A mobile-friendly, browser-based street-football prototype.

## Play locally

Open `index.html` in a modern browser. Desktop controls are WASD/arrow keys to move, Space to shoot, and Shift to sprint. Phones display on-screen controls.

## Publish with GitHub Pages

1. Create an empty public GitHub repository, for example `cage-kings-street-football`.
2. Upload these files to the repository root.
3. In repository **Settings → Pages**, select **Deploy from a branch**, then select `main` and `/ (root)`.
4. GitHub will give you the public game address.

This prototype intentionally has no external packages, so it deploys directly on GitHub Pages.
